# Image Toolbox

一个功能丰富的在线图片处理工具，支持多种图片处理操作。

## 功能特性

- 🔄 **格式转换** - 支持 JPG、PNG、WebP、BMP、GIF 格式互转
- ✂️ **图片裁切** - 自由选择区域进行裁切
- 📐 **调整尺寸** - 自定义尺寸或使用预设尺寸
- 💧 **水印添加** - 添加自定义文字水印
- 📦 **图片压缩** - 调整压缩质量和输出格式
- 📷 **证件照处理** - 更换证件照背景颜色
- ✨ **智能抠图** - 一键移除背景生成透明PNG
- ◫ **九宫格切图** - 将图片切成3×3九宫格
- 🎨 **自由拼贴** - 自由创作拼贴画
- ⬛ **二维码生成** - 生成自定义二维码

## 使用说明

1. 打开 `index.html` 文件
2. 选择需要的功能标签
3. 上传图片或输入内容
4. 根据需要调整参数
5. 点击下载按钮保存处理后的图片

## 技术特点

- 纯前端实现，所有图片处理均在浏览器本地完成
- 无需服务器，无需注册，打开即用
- 支持中文/英文自动切换（根据浏览器语言）
- 响应式设计，支持移动端

## 浏览器支持

- Chrome (推荐)
- Firefox
- Safari
- Edge
